# v0.5.5 诊断后台化与分析经验整理

## 授权与范围

2026-10-15 用户授权吸收可复用的游戏分析经验，并提交、发布全部当前改动。此前仅本地实现的宿主诊断后台化纳入本次正式版本；历史本地授权记录保留在 `MODULE_DIAGNOSTICS_ASYNC_LOCAL.md`，不改写过去的发布状态。

- 主程序、更新器、离线页面核验器同步递增到 0.5.5；Host API 8、SDK 与资料/目录协议不变。
- 诊断在后台执行，与连接检查共用门禁；取消不终止已进入的同步模块调用，也不提前释放门禁。切换游戏/进程/会话、模块停用/替换及正式退出后不展示旧报告或错误。
- 补齐正式模块包回归：按清单分别验证动态未知构建与精确构建拒绝；修复诊断私有方法的反射参数；合法的空贡献者数组不等于缺失元数据。
- 通用经验同步到本机 `offline-game-analysis` 技能和公开的 `GAME_EXTENSION_GUIDE.md`：单位校准、重算追踪、掉落发生/稀有度/尝试/数量/特殊分支分离，以及本地化读取的线程与副作用边界。技能目录不是 Git 仓库，公开指南保留可追溯版本；不把游戏公式、枚举或偏移写进通用技能。
- 游戏专属分析仍保留在对应模块目录。现有模块资产与目录不改，不重新发布已经核验的模块。
