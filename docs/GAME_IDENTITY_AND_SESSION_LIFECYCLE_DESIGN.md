# 游戏身份与会话生命周期修复（2026-10-07，本地未发布）

发布状态：这些修复纳入 v0.5.0，见[集成复核与发布记录](RELEASE_0_5_0_INTEGRATION_REVIEW.md)。标题及下文的本地未发布信息是原实施轮次的历史记录；后续用户已另行授权集成检查通过后提交和发布，原检查证据保留。

## 范围

只修复本轮已复现的三项：同名进程误合并、移出期间切换游戏导致会话错位、退出回正失败后仍处于退出状态。保留既有未提交改动。本轮不提交、推送、打标签、发布、递增版本或重新打包；不改模块仓库、SDK/API、Schema、布局、真实游戏数据与存档。

## 详细方案

### 1. 游戏身份与连接

- 进程名只筛选候选，不作为合并、更新路径或覆盖模块 ID 的依据。空路径不算路径匹配。
- 提取内部纯规则：优先唯一规范化路径，其次已执行 Supports 验证的模块稳定 ID/旧 ID，最后唯一已有构建指纹。冲突或多义结果不自动合并。已声明另一个模块身份的条目不被当前模块覆盖；空指纹不能匹配空指纹。
- 顶部连接可以连接未入库进程；无法确认身份时使用独立临时会话，保存入库时生成新条目。已知构建换目录或模块验证成功的新构建仍能关联原档案。
- 游戏库连接先优先找到精确路径；无路径匹配时只从唯一候选安装路径寻找进程。连接前完成数据进程构建/模块身份确认，无法证明是所选游戏时明确失败，不改旧档案或当前会话。父子进程路由和同游戏多实例排序不变。
- 指纹异步计算绑定原游戏操作上下文；实际连接前核对进程 PID/创建时间。路径发现与版本匹配共用同一身份规则；匹配后的会话、游戏 ID、字典、连接标记一同绑定。
- 已安装模块与游戏库协调也不能按进程名抢占条目：先稳定模块 ID/已加载旧 ID，再唯一非空已知构建且未声明其他模块的档案，否则创建该模块的独立条目。未知构建下载发现仍按进程名，安装后的运行兼容门禁不变。

### 2. 移出期间的视图归属

- 游戏档案和模块删除仍针对最初选中的 A，不能因切换到 B 改删 B。
- 完成时按当前实际会话和选择判断。当前仍为 A 的连接时，保存完整会话快照，移除游戏身份与已保存版本，完整恢复为 A 的临时连接，保留通用扫描和倍速；不只替换后台引用。
- 当前已经是 B 时，不修改 B 的选择、进程、指纹、版本、扫描、页面或倍速服务。A 若仍连接但不再展示，安全回正并断开 A 后移出，避免生成无游戏条目且后台不可见的孤儿会话；回正失败保留 A 的档案和会话，提示重试，不动 B。
- A 没有连接或等待期间退出时，仅移除 A；只有当前选择仍是已移出的 A 才选择剩余条目。A→B→A 使用完成时完整的当前 A 会话，不恢复过时快照。
- 卸载失败保留游戏档案；文件占用的重试/下次启动清理机制沿用现有实现。

### 3. 可失败的退出准备与正式清理

- 实际倍速切换尚在运行时，退出明确等待用户稍后重试，不能并发释放同一倍速服务；两秒按钮冷却本身不阻止退出。
- 准备阶段只尝试安全回正/解除本机服务。尚未全部成功前不设退出标记、不取消下载或扫描、不销毁页面/扫描、也不停止窗口连接监测。已成功回正的游戏保持 1 倍并同步状态，不能为了恢复界面自动再加速。
- 全部准备成功后才提交退出状态，取消任务并释放服务。正式清理逐项尝试；清理故障不能让窗口留在半销毁状态。重复退出幂等。
- 窗口通过内部可测试的关闭协调方法决定是否允许关闭；准备失败保持计时器原状态并显示原错误，提交后停止计时器。正常退出行为不变。

## 写代码前检查

以下检查完成后才修改实现；检查结果追加在本节，不能把测试计划当作执行证据。

### 第一遍：需求与方向（完成）

对照三个隔离复现、README 的换目录/保留连接约定与现有架构：不能用严格路径唯一规则直接切断合法的换目录关联；模块稳定身份必须来自 Supports 已验证的适配器，而不是仅从进程名找到的下载目录。同名模块协调也属于同一身份入口，必须一并收紧。明确保留当前 A 的临时连接；切换至 B 后 A 的不可见会话安全断开，B 不受影响，文档须说明该差别。

### 第二遍：时序与失败边界（完成）

逐项跟踪 Attach/Match/Add/Reconcile、Delete/Remove、Shutdown/Closing 的调用顺序。确认连接前异步验证必须捕获旧上下文，且复用同一数据进程组和指纹，防止验证 A 后重新路由到另一进程。旧资料若没有组合指纹，只能由完整已保存的 EXE/assembly/metadata 分量确认 IL2CPP 构建，只有 EXE 的旧记录仍不能证明 IL2CPP 身份。移出 A 前不能先把 A 会话从字典拿掉再尝试回正，以免失败后产生孤儿；当前 A 转临时连接必须使用完整恢复入口。退出准备前不取消任务；正式清理失败仍应允许已经提交的退出完成。

### 第三遍：兼容性与可验证性（完成）

核对既有模块安装测试中的旧分量指纹、扫描迟到响应的 shutdown 测试、窗口构造与固定布局测试。新纯规则和边界回归可以在隔离目录、当前测试进程的只读身份以及无原生调用的故障状态上完成，不必读写真实游戏。确认不增公开 SDK、不改版本/Schema、不改下载发现与运行兼容；原正式 ZIP 与 SDK 源文件散列已留作交付对照。实现后必须新增这些场景的回归，而非仅再次运行原测试。

## 验证计划

- 身份：同名不同路径、明确路径优先、空路径、空指纹、多个同构建候选、模块身份冲突/旧 ID、已知构建换目录、模块预装条目首次连接、无法确认的库内连接拒绝、入库不覆盖旧条目、同名模块不抢占游戏档案。
- 移出：保持 A、A→B、A→B→A、无连接 A→B、等待中 A 退出、文件占用、回正失败；检查选择/进程/会话/速度服务/指纹/版本/扫描与新操作一致。
- 退出：准备失败前后的操作上下文、扫描/下载/锁定/页面与计时器保留；部分游戏已回正时状态真实；重试成功、正常关闭、重复调用、倍速任务运行与纯冷却的区别；不调用真实游戏的写入。
- 第一遍实施后检查：逐项核对规则与差异。第二遍：运行针对性边界回归。第三遍：完整 Release 构建、完整冒烟与三个真实模块包加载/页面核验，复核文档、旧发布包散列、两个仓库 HEAD/状态和遗留进程。

## 实施与验收

### 第一遍：实现与失败边界复核（完成）

逐项复核身份解析与连接/匹配/入库/模块协调入口、移出完成后的会话归属、退出准备/提交以及窗口关闭协调。规则已经落在共用身份解析器，进程名不再用于合并档案；连接复用同一数据进程组和已计算指纹，在适配器 Supports 返回后再次核对操作上下文。旧 IL2CPP 版本只在完整分量身份匹配时补组合指纹，不把仅 EXE 相同的历史版本升级成当前构建。

移出当前 A 时完整恢复为临时会话；切换到 B 时只安全断开 A，保留 B。模块文件卸载成功后立即同步 A 的安装标记；若后续回正失败，保留档案/会话但不伪装模块仍已安装，实际重试可以继续。实际倍速任务尚未完成时移出/退出有明确门禁，按钮冷却不等于任务正在运行。退出准备失败不提交退出状态、不取消业务任务、不停止窗口监测；提交后的清理逐项尝试，不把窗口留在半销毁状态。

### 第二遍：针对性边界回归（完成）

新增游戏生命周期回归最终通过 89 项断言，覆盖上述身份冲突、合法换目录、预装模块/旧 ID、历史指纹迁移、同名模块协调，以及移出时保持 A、A→B、A→B→A、未连接/退出、文件占用、回正失败、倍速任务运行和实际重试。检查了视图与后台进程、扫描、版本、指纹、会话及倍速服务是否一致。退出回归核对失败时任务/上下文保留、部分游戏已回正的真实状态、重试成功与幂等。

另有 5 项窗口关闭断言，验证准备失败保留连接监测、成功重试停止监测，以及提交后清理异常仍允许关闭。所有故障注入和测试数据都在隔离目录/测试进程中完成；不写真实游戏或存档。

### 第三遍：完整回归与交付边界复核（完成）

最终 Release 构建成功，0 警告、0 错误。完整冒烟通过：163 项模块/实例可靠性断言、207 项安全边界断言、89 项游戏生命周期断言，以及既有稳定性、下载反馈、布局、窗口关闭、编解码/扫描/写入/构建指纹检查。实际加载现有 WorldApart v1.3.3、Fzzml v2.1.3、Last Epoch v0.5.4 的模块包，分别核验 2、2、5 个页面，共 9 个页面。

验证中收紧了测试本身的隔离边界：沿用原样例适配器夹具，避免新增适配器被样例模块的导出扫描识别为额外插件；进程身份测试改为先验证拒绝过期实例，再独立构造连接后失效场景；扫描标记断言检查既有结果库的完整候选，而不只假设标记必在 10000 条预览内。早先一次扫描标记失败未保留完整结果，不能据此断言其唯一原因；后续完整回归已通过，未修改生产扫描范围或放宽缺失标记断言。

README、架构和发布说明已同步本地未发布行为，`git diff --check` 通过。主程序仍为 v0.4.9，Host API 7、库 Schema 7 未改变；SDK 源文件、原正式 ZIP 和原完整离线 ZIP 的 SHA-256 与本轮开始时一致。主程序和模块仓库 HEAD 均未改变，模块仓库保持干净，既有未提交改动保留；回归结束无残留测试/搜索进程。

### 交付限制

修复只留在本地源码与测试构建中，没有提交、推送、发布、递增版本、重打分发包或替换正在使用的程序。模块包页面加载通过不代表真实游戏数值效果已重新验证；本轮没有进行该类验证。多义身份仍安全拒绝自动关联，可从顶部选择实际进程建立独立条目，不自动合并/修复已有档案，也不做自动回退或自动重新加速。

## 后续本地补充：卸载后的锁定归属（2026-10-07，未提交、未发布）

上述历史修复已随 v0.5.0 发布；本轮修复卸载模块取消所有游戏锁定、却仅恢复当前游戏的问题。卸载与更新/回退停用入口按模块稳定 ID/旧 ID 选取受影响会话，只暂停这些任务。无关游戏不换 Token、不停后台锁定；受影响会话的通用字段按自己的进程、版本和构建恢复，专属字段在模块停用后保持不可用。

恢复前核对会话仍登记、档案/版本有效、构建匹配及未正式关闭；卸载等待期间断开或关闭也不能重新启动。测试同时覆盖当前/后台会话、规范/旧 ID、卸载/停用、通用锁定恢复、旧构建拒绝，以及真实异步文件占用等待期间的断开/关闭。方案与执行结果见[后台操作边界修复](BACKGROUND_OPERATION_BOUNDARIES_LOCAL.md)。本轮只留本地，不修改现有正式 v0.5.0 资产。

## 后续本地补充：排队字段与页面上下文（2026-10-07，未提交、未发布）

字段级任务排队不延长原游戏操作的有效期：排队开始和结果返回核对游戏/版本/连接/操作代及字段成员，模块停用后旧排队写入不得使用旧适配器。页面服务在 Dispatcher 执行时核对页面 Token 与原适配器/进程/构建，旧状态/错误不进入新页面；输入和保存不向失效页面返回有效结果。保存弹框期间换游戏/版本，以及读取保存字段期间销毁页面，都在资料新增前拒绝。保存字段刷新核对实际进程句柄启动身份。细节与验证见[字段顺序与页面有效期](FIELD_ORDER_AND_PAGE_LIFETIME_LOCAL.md)，SDK 和既有正式资产不变。
