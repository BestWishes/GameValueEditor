## 发布前方案三遍复核

- 第一遍（需求和方向）：实际游戏名称与备注分离，公共同名窗口排除，小更新仍认作同一游戏。通用宿主修复不会虚增模块版本或改变其业务规则。
- 第二遍（安全和依赖）：正式包/目录输入及最新完整离线内容受保护，旧核验脚本不再依赖固定离线别名。未知文件不猜删，默认不执行 Apply。索引三份与实体旧资产删除分离，尊重本次先预览的授权。
- 第三遍（来源和交付）：先验证/提交，再从干净源码构建；标签、ProductVersion 和资产散列一致。发布失败只恢复同一个上传步骤，不覆盖 0.5.3 资产；完整离线包本地交付。
