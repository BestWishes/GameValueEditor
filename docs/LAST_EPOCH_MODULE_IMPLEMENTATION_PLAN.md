# Last Epoch 离线专属模块实施方案

状态：2026-10-03 已完成 Last Epoch 1.5.1 / Steam BuildID 25672295 的语义重定位验证；本轮不提交、不发布，只生成本地完整测试包。模块只接受带 `--offline` 参数的进程。

## 本次范围

- 人物属性：把原有字段纠正为“剩余天赋点”和“剩余技能点”；技能点改走技能经验/等级权威路径，不再写会被重新计算覆盖的临时附加点。力量、敏捷、智力、协调、活力、移动速度加成、经验获取加成和掉落加成目前只读：直接调用和主线程回调均在实机导致进程退出，找到安全权威路径前不得开放写入。
- 装备编辑：只编辑当前放入熔炉主槽的一件装备，按装备实际类型显示并修改锻造潜能（含鲜血/寒冰名称）、编织者意志、编织者之触和传奇潜能；不读取穿戴栏或普通背包装备。
- 不提供普通背包物品数量修改。实测当前角色背包容器中的 78 条记录数量全部为 1，同类资源也各占独立格；按类型合并总数会破坏原始槽位和物品身份。
- 资源：对应游戏背包的“资源”页，列出全部词缀碎片、符文、雕文和副本钥匙等固定资源槽位。未持有的资源也显示为 0，并允许改为大于 0；实现必须按稳定资源 ID 创建缺失记录，不能伪造普通背包堆叠。
- 异界进度：提供角色最高腐化，以及已有时间线记录的腐化、稳定度、深度和奥罗比斯凝视。未进入异界时只显示全局最高腐化，不创建时间线、不解锁内容。
- 世界功能：提供“开启当前地图全部视野”和摄像头视野角度调整。地图功能调用游戏自己的迷雾保存与刷新路径；摄像头通过游戏自己的 FOV 接口调整，并标注为当前运行/场景状态。
- 游戏版本：从 `UnityEngine.Application` 读取游戏声明名称、游戏版本和构建 GUID；Unity 引擎版本只作为独立技术信息，不能冒充游戏版本。
- 仅当能找到当前构建中稳定、可复读且不会重复生成/破坏场景的权威入口时才提供怪物数量倍率。当前已知的场景刷怪密度字段只在生成阶段被消费，不足以安全实现，因此本轮不加入。
- 不实现仓库、剧情进度、具体技能或专精节点。

## 身份与安全边界

- 模块 ID：`game.last-epoch`。
- 编辑器 ID 使用稳定语义名称，不把地址或 RVA 作为保存字段身份。
- 清单登记 EXE、GameAssembly.dll 和 global-metadata.dat 的实机验证 SHA-256；运行期再按 IL2CPP 类、字段和方法语义解析当前地址并校验结构，不因单纯 RVA 平移拒绝兼容小版本。
- 语义成员缺失、函数地址越出当前 GameAssembly、在线进程、失效对象、超范围目标值均拒绝写入。
- 禁止从 `CreateRemoteThread` 创建的 IL2CPP 工作线程调用任何 Unity 或游戏业务方法。最新实机证据表明，即使线程已附加 IL2CPP 域，这种调用仍会触发 `UnityPlayer.dll` / `GameAssembly.dll` 崩溃。只允许直接读取稳定字段、写入已验证的权威字段，或采用另行验证的主线程桥接/安全存档事务，并在写后复读。

## 三轮审查记录

### 第一轮：数据安全

- 所有入口先验证离线参数，并要求精确哈希命中或完整 IL2CPP 语义结构校验通过。
- 只修改已确认类型、字段与集合；不扫描猜测地址，不创建异界解锁记录。
- “剩余天赋点”保留累计获得点数的权威写法；“剩余技能点”改为同时维护技能经验与等级，并由游戏函数计算等级门槛，避免加点后被覆盖。
- 五项基础属性和移动/经验/掉落加成通过玩家实时统计对象及游戏更新函数处理；物品稀有度、掉落数量等没有证实为玩家全局权威属性的项目不冒充功能。
- 词缀碎片通过游戏本地化接口取名；游戏声明版本通过 `Application.version/productName/buildGUID` 获取，Unity 版本单独显示。
- 怪物数量没有找到安全的全局权威入口，不以场景临时密度字段拼凑实现。

### 第二轮：持久化与生命周期

- 人物和异界只更新已确认的权威数据，并直接设置 `CharacterData` 的 `EntityFlags.Dirty` 与 `DirtyTime`；由游戏自己的 `DataStoreCache` 更新循环保存。该替代路径已经离线反汇编确认，但尚未实机验证，恢复开发后必须先做备份和最小可逆测试。
- 剩余技能点写入技能经验和等级后保存并复读；基础属性和倍率项属于实时统计对象，只承诺当前游戏运行有效。
- 普通背包不再进入编辑范围。
- 资源写入必须区分“已有记录改数量”和“缺失记录从 0 创建”。已有记录只有在确认权威字段及保存路径后才允许直接写；缺失记录必须创建完整、稳定身份的资源记录。旧版 `GlobalAddShard`、`ItemData.set_Quantity`、`ItemData.GetDummyData`、`SingleSubTypeItemContainer.TryToAddItem` 等远程工作线程调用路径全部判为不安全，不能用于交付。
- “开启当前地图全部视野”只处理当前已经加载的地图迷雾状态，最大按游戏保存格式的 64 个区域写入，随后调用游戏自己的保存和即时刷新路径。
- 摄像头视野角度通过 `CameraManager.AdjustCameraFov` 修改并复读虚拟摄像机镜头值；场景切换或重启后的恢复由游戏决定，不宣称持久化。
- 禁止使用 `System.Action + PlayerLoopHelper.AddContinuation` 注入回调，也禁止从附加线程强制调用 `PlayerFinder.savePlayerData`：前者已触发延迟 APPCRASH，后者曾让 `savedItems` 从 135 条缩到 60 条并使角色无法载入。背包目标总数相同时必须直接返回，数量变化时按差额调整现有堆叠，不得无条件把同类型记录清零。
- 每次写入后复读；宿主或游戏重启后由语义键重新定位，不依赖临时地址。

### 第三轮：界面与扩展性

- “本游专属”继续使用左侧竖向编辑器导航，右侧显示当前编辑器内容。
- 为集合、主从和属性表补充可复用的数据契约；Last Epoch 不把游戏私有结构泄露给宿主。
- 资源使用分组筛选；至少区分“词缀碎片”“符文与雕文”“副本钥匙”。不存在的资源仍显示数量 0；普通背包编辑器从模块中移除。
- 人物字段使用玩家实际概念“剩余天赋点/剩余技能点”；“世界功能”作为独立内容编辑模块承载当前确认安全的功能。
- 保留既有字段语义键，修正显示名称而不破坏快捷入口；新增字段使用稳定语义 ID。
- 快捷入口保存的是 `编辑器 ID + 实体 ID + 字段 ID`。
- 最终只生成本地完整离线 ZIP，不提交、不推送、不创建 Release。

### 精确功能范围

- 人物属性新增并按游戏真实语义显示：移动速度、效果范围、近战范围、经验倍率，以及游戏中确实存在的物品掉落相关属性。不得把无法证明的字段伪装成“稀有度”“掉落概率”或“掉落数量”。
