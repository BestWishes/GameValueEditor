# 路线图

## v0.1

- 游戏库与版本档案。
- 置顶、锁定、删除保护。
- 基础精确扫描和变化过滤。
- 玩家手动命名字段。
- 模块偏移和会话地址。
- Windows x64 自包含发布包。

## v0.2

- 未知初始值扫描。
- 字节数组和 UTF-8/UTF-16 搜索。
- 批量多类型搜索。
- 字段编辑历史与一键撤销。
- 扫描会话保存和恢复。

## v0.3

- 多级指针扫描。
- AOB 特征定位器。
- 字段分组管理和拖放排序。
- 游戏图标提取。

## 后续

- Unity Mono / IL2CPP 适配器。
- Lua / LuaJIT table 适配器。
- Unreal Engine 适配器。
- 可审查的社区游戏配置导入导出格式。
