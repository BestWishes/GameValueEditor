# 路线图

## 已完成

- 游戏库、构建隔离、字段备注、分组、置顶和锁定。
- 完整候选扫描、再次过滤、撤销、少量候选实时刷新和批量修改。
- 参数化搜索套路、x64 游戏加速和多游戏并行会话。
- 多进程游戏归组、数据进程重建和 Steam/游戏/引擎版本分栏。
- 可选游戏模块下载、校验、影子加载、卸载、贡献者和正式版更新器。
- Host API 4 模块自有页面、字段级生命周期和真实模块包兼容验证。
- Host API 5 通用兼容性诊断、模块只读扩展检查和复制报告脱敏。
- Host API 6 模块自有 WPF 页面、显式页面生命周期和十进制逐次发布版本规则。
- Host API 7 宿主视觉资源契约：模块自由设计页面结构，宿主统一主题、字体、控件样式和间距。
- 主程序与模块独立版本的显式兼容映射、各自手动回退，以及每组最近 3 个正式包的自动保留。
- 发布资产提交号追溯：提交后从干净工作树构建，二进制、标签和远端分支指向同一提交。
- 正式版专用发布流程；不再维护 preview 更新通道。

## 候选方向

- 多级指针和 AOB 特征定位器。
- 未知初始值、字节数组和 UTF-8/UTF-16 搜索。
- 字段编辑历史与可控撤销。
- 扫描会话保存和恢复。
- 可审查的社区游戏配置导入导出格式。
- 模块仓库按实际需要沉淀可选的共享控件，不把新页面形态加入宿主硬编码协议。

新方向必须保持离线单机边界、未知构建安全失败和模块语义身份，不以支持数量换取未经验证的写入。
