# 路线图

## v0.1

- 游戏库与版本档案。
- 置顶、锁定、删除保护。
- 基础精确扫描和变化过滤。
- 玩家手动命名字段。
- 模块偏移和会话地址。
- Windows x64 自包含发布包。

## v0.2

- [x] 批量多类型搜索。
- [x] 参数化搜索套路及“所有套路”。
- [x] 浅色/深色主题与进程图标。
- [x] 游戏版本档案保存首选套路。
- [x] `fzzml` 构建专属背包实时适配器。
- [x] `fzzml` 实时写入、游戏存档、重启后重新定位验证。
- [x] “本游专属”页、背包枚举及名称/数量筛选。
- [x] 扫描撤销、首次值列、少量候选实时刷新和双击试改。
- [x] 字段备注名称/分组/当前值编辑与数值锁定。
- [x] 扫描结果和专属背包列表标准多选与批量修改。
- [x] x64 进程通用游戏加速与连续回正。
- [x] 友好版本选择、搜索清空及搜索状态与当前游戏解耦。
- [x] 新游戏搜索套路/专属适配器扩展文档。
- [ ] `fzzml` 搜索、过滤、保存、写入、重启后的完整应用界面回归。
- [ ] 未知初始值扫描。
- [ ] 字节数组和 UTF-8/UTF-16 搜索。
- [ ] 字段编辑历史与一键撤销。
- [ ] 扫描会话保存和恢复。

## v0.3

- [x] 多游戏同时连接与连接优先排序。
- [x] 游戏图标持久化和连接状态显示。
- [x] 专属适配器按需模块化下载、校验与隔离装配。
- [x] GitHub 正式版应用内检查、延迟安装与独立更新器。
- [x] 游戏版本收录日期与便携式模块/更新数据目录。

- 更多引擎和游戏专属适配器。
