## 实施决策

- 本游专属 Tab 永久可见；没有模块时显示提示，这一条覆盖早期“无专属逻辑时隐藏 Tab”的方案。
- 游戏连接、扫描、加速和锁定必须按会话隔离，不允许把一个游戏的 PID、适配器或扫描地址带到另一个游戏。
- 下载模块和应用更新都要先写入临时文件、校验 SHA-256，再原子替换或标记待安装。
- 不在没有用户明确要求时自行提交、推送或发布。

## v0.3.0-preview.3 交互与小数倍速任务

> 用户已明确要求：完成本节后直接提交、推送并发布，然后关闭电脑。

### 顶部与游戏库布局

- [x] 顶部控件顺序改为：主题、刷新进程、进程下拉框、连接；进程下拉框右侧只保留“连接”。
- [x] 顶部移除“保存到游戏库”，右上角“连接”保留，并与编辑区“连接”共用命令和状态。
- [x] 左侧游戏库的“删除游戏”改名为“从库移出”。

### 编辑区入库与连接操作

- [x] 游戏名称后留出间距，依次显示“未入库/已入库”、“保存到游戏库”、“从库移出”。
- [x] 未入库时保存弹出“备注名称”；已入库时再次保存仍弹窗，并用新名称重命名现有条目，不创建重复项。
- [x] 编辑区和游戏库的“从库移出”行为一致；锁定条目不能移出。
- [x] 已连接游戏从库移出时只删除入库记录，不断开当前进程，界面立即变为“未入库”。
- [x] 连接状态行右侧留出间距，增加“连接”和“断开”；顶部与编辑区连接按钮状态同步。
- [x] 保存、移出、连接、断开、刷新期间设置精确的忙碌状态与短暂防重复点击冷却。

### 小数倍速与减速

- [x] 倍数标签改为“倍数（0.01~100.00）：”。
- [x] 输入范围改为 `0.01` 至 `100.00`，最多两位小数，禁止零、负数、非数字和越界值。
- [x] “加速”改为“应用倍速”；支持小于 1 的减速、等于 1 的正常倍速和大于 1 的加速。
- [x] 状态分别显示“x 倍减速中”、“正常倍速中”、“x 倍加速中”。
- [x] 应用新倍数、回正、断开和关闭编辑器时保持虚拟时钟连续，不能倒退、卡死或遗留倍速。
- [x] 补充 `0.01`、`0.5`、`0.75`、`1`、`2.5`、`20`、`100` 以及连续重设/回正的自动测试和原生目标测试。
