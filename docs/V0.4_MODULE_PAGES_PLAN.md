# v0.4.0 模块自有页面改造

## 目标

- “本游专属”顶层入口、模块管理栏、“检查新有”、安装、卸载、贡献者和右侧页面容器属于主程序。
- 游戏模块决定页面清单、稳定编辑器 ID、页面名称、顺序、说明、空状态、标准页面角色和字段生命周期。
- 普通新增游戏只开发游戏模块，不在主程序中增加游戏 ID、页面名称、固定 Tab 或编辑器 ID 后缀判断。

## 契约

- Host API 4 增加 `IGameEditorPageProvider`，每个编辑器显式注册为背包、人物属性或通用实体页面。
- Host API 4 增加可选的 `IGameEditorFieldPolicyProvider`，由模块声明字段是否仅本次运行有效以及是否允许锁定。
- API 4 模块必须为每个编辑器注册且仅注册一个页面；背包和人物属性页面每个游戏包最多各一个。
- API 2/3 模块保留通用兼容映射；所有官方模块升级后不再使用兼容推断。

## 主程序改造

- “本游专属”的竖向导航绑定动态页面集合，删除固定的背包、人物、装备、资源、异界和世界功能 Tab。
- 通用页面模板继续由主程序提供，页面内容和操作由当前模块注册信息及适配器数据驱动。
- 删除 `.equipment`、`.materials`、`.monolith`、`.world` 后缀查找，以及特定游戏人物字段的锁定特判。
- 保持“检查新有”原标签不变；右下角应用更新按钮仍叫“检查更新”。

## 模块与贡献者

- fzzml、WorldApart 和 Last Epoch 分别声明自己的页面注册。
- Last Epoch 声明人物页中点数字段可持久化，其余运行期字段不可锁定；异界空状态由模块提供。
- 补齐 Last Epoch 的贡献者生成记录，使已安装包和远程目录都能启用“贡献者”按钮。

## 验证与发布

- Release 构建主程序与全部模块，运行宿主冒烟测试、模块清单校验、标准包启动测试和更新器测试。
- 检查主程序源码中没有官方游戏 ID、固定游戏页面名称或编辑器后缀分支。
- 发布主程序 v0.4.0，以及 fzzml v2.1.0、WorldApart v1.3.0、Last Epoch v0.5.0；先验证不可变模块资产，再更新公开目录。
