# 实际字段协调与模块停用边界（2026-10-07，本地方案）

## 范围与已确认问题

后续复查发现本轮尚未覆盖的解锁与整页读取边界，当前修复见[后续方案](REFRESH_AND_UNLOCK_BOUNDARIES_LOCAL.md)。以下保留本轮原始设计/验收证据；“模块停用后的旧读取”当时仅指保存字段刷新，不等同于全部旧式/模块自有整页读取。

用户批准本轮修复，仍只留本地，不提交、推送、发布、关机或覆盖现有分发包。保留之前未提交改动，不连接真实游戏。四个隔离探针确认：正常新增可保存同一模块字段的两个条目；两条目的手改可并发，锁定目标 10/20 会交替写入；真实共享背包页面的修改可被保存字段旧锁定覆盖；模块停用后旧刷新成功和失败都会覆盖停用提示。这是上轮按条目协调的覆盖缺口，不是撤销原修复。

## 详细设计

### 1. 以实际目标协调，不合并或删除用户条目

- 运行范围是 PID、进程启动时间、构建指纹。模块目标是规范模块 ID（含旧 ID 归一）与语义字段键；URI 转义形式不同的同义键归一，原始物品名保留大小写。不同字段、不同进程和不同构建互不阻塞。
- 原生目标先在已验证进程中解析地址，以实际字节范围协调，覆盖模块偏移/本次地址两种定位及 4/8 字节部分重叠。多字节预留在短临界区内一次完成，避免部分重叠队列死锁；不把整个游戏串行化。
- 沿用 FIFO、请求时失效旧读取、后台只取空闲目标和异常释放规则。运行协调器使用弱范围缓存，活动目标/操作持有范围，不能因换条目或重连同一实例而绕过未完成调用。
- 重复条目的名称、分组、备注不变。成功手改同步同一目标的显示；锁定目标只更新操作开始时存在且返回时仍保持原锁定状态/目标的别名，保留期间的显式解锁或目标调整。原生别名按各自类型/倍率格式化；部分重叠的其它锁定暂停，不凭局部字节猜完整目标。
- 旧资料同一目标存在不同锁定值时，不自动挑一个，也不交替写入。后台显示“锁定已暂停：同一字段存在冲突目标”；手动明确修改可统一仍未改变的锁定目标，或由用户解除锁定。锁定操作针对同一目标的别名同步；原生冲突按编码字节比较。

### 2. 页面自由布局，数据写入通过宿主桥接

- 新增独立 SDK 能力接口 `IGameEditorFieldOperations.WriteFieldAsync`，不修改既有宿主服务接口或页面上下文构造参数。新增页面提供者标记承诺使用该桥接；Host API 8 模块由加载器核验标记。
- 宿主给页面的作用域服务实现写入能力，绑定原进程、构建、适配器与页面生命周期。在 Dispatcher 上检查、排队、返回及资料保存收尾核验；排队期间页面失效不执行，已开始同步写入只能等待结束，不能声称撤销。
- 三个模块的共享背包/人物/实体页面及 Last Epoch 资源页面改走桥接，保留现有布局、分类、主题与模块内部验证/保存路径。旧宿主不支持 API 8 时明确拒绝新模块，不能假装兼容。
- 旧 API 6/7 页面包仍可加载，状态/错误生命周期包装仍生效；由于其内部直接写入无法由宿主拦截，对其保存字段锁定明确暂停并禁止新启用，避免页面被旧锁定回写。旧 API 1–5 宿主页面的写入也进入协调器。
- 本轮源码 Host API 升至 8，两仓库 SDK 源同步、CLR 程序集标识不变；产品和模块发行版本暂不递增，不生成正式包。现有 catalog/ZIP 继续描述已发布 API 7 包，不改成尚未发布的 API 8 元数据。未来获准发布时先按十进位 +0.0.1 递增各自版本，再生成真实包及目录。

### 3. 停用后的旧读取不得回填

- 保存字段刷新在开始及成功/失败返回时核对原适配器实例，停用/替换后丢弃值、错误及整批完成提示。保存模块字段的语义读取和保存收尾也核对适配器，防止无页面验证器的公共入口漏检。
- 同一目标的新增保存读取也进入队列，不因新增别名绕过已排队的写入。原生定位失败与真实模块读取错误继续明确反馈；不增加自动重试或自动回退。

## 写代码前三遍检查（完成）

1. 方向检查：保留模块 UI 自主权，只约束写入边界；重复保存不删资料，身份不使用备注/显示名或地址猜模块语义；不能声称旧不可变模块包自动获得桥接。
2. 并发与失效检查：覆盖重复条目、新增保存、页面写入、快捷字段、旧宿主页面、原生重叠、锁定冲突、显式解锁、排队取消、模块停用、保存失败。共享目标预留必须原子完成，失效检查必须在真正执行/回填时发生。
3. 验证与交付检查：先加入确定性回归使旧逻辑失败，再实施；测试只用模拟适配器/测试进程内存，避免向样例插件程序集新增第二个静态适配器导出。分别验证新源码三个模块九个页面与旧 API 7 包安全降级；完整回归、UTF-8/链接/差异/包哈希三轮检查后更新记录。无提交或发布授权。

这些验证证明本轮入口顺序、失效及兼容边界，不证明任意新游戏字段对真实玩法生效。模块仍须按稳定语义键暴露同一目标并在内部完成构建/线程/业务保存验证；宿主无法从通用扫描地址推断它对应哪个模块语义字段，也无法拦截旧包直接调用适配器的所有手动操作。未接入桥接的旧自有页面因此暂停字段锁定，而不是声称全部获得新能力。已经执行的同步写入或完成的资料保存不能被取消回滚。
