# v0.5.0 扫描失败定位与修复

## 范围与详细方案

用户批准先处理发布门禁中间歇出现的自进程扫描失败，再继续提交和发布。只扫描测试进程自有缓冲区，不连接真实游戏，不改模块/API/Schema，不跳过标记断言，不采用“重跑到通过”作为发布依据。

1. 保留原失败的 `total=0, preview=0` 事实。加入无地址的扫描统计：枚举调用/终止错误、枚举区域数、尝试和成功读取数。统计仅帮助定位，不改变匹配、读取和枚举行为。
2. 用有明确次数上限的独立诊断模式及原完整测试捕获原因。失败立即终止；正常运行不是根因已解决的证据。
3. 根据证据建立确定性回归，先证明旧逻辑失败。若需要生产修复，再明确枚举错误与正常地址空间结束的边界、读取失败后的有限回退与跨块匹配规则；不得扩大到不可读/保护页、解除保护或暂停目标进程。
4. 修复后做三遍检查：源码/错误边界；确定性故障回归与原完整回归；干净提交的标准包、更新器及完整离线包。同步本文和集成发布记录，再执行单一 v0.5.0 发布流程。

## 写代码前的三遍检查

1. **方向**：自扫描失败可能来自测试条件，也可能影响生产扫描；未捕获原因前不做确定归因。当前三次有界完整诊断均通过，不视为修复。
2. **安全**：统计不输出路径/PID/实际地址/内存内容，不改变超时、游戏内存写入、候选数量或结果预览上限。故障注入仅在内部测试入口。
3. **验证**：原匹配断言保留，先红后绿；保留真实自进程扫描及超过 250000 候选的原测试。任何未解释的新失败都暂停发布。

## 实施证据

正常及 GC 压力各 12 次有界自扫描、额外三次带统计的完整回归均未再捕获历史失败。统计显示确有大块读取失败；Windows 的 ReadProcessMemory 要求整段可读，区域在枚举后变化时旧代码会跳过整块。这是可确定重现的生产缺口，但不能据此断言历史那次失败唯一由它导致。

## 补充修复方案与三遍预检查

1. 引入内部只读扫描访问接口和内部测试构造入口；公开默认行为仍打开指定进程，接口不进入 ModuleSdk。用真实自有 VirtualAlloc 区域，在枚举后把中间一页改为 NoAccess，保留前后标记页可读。固定回归须先在旧分块算法下失败。
2. 保留 1 MiB 正常快路径。失败块仅按系统页边界拆分，逐页读取并保留最多 7 字节重叠；重叠跨坏页时仅回读本页，无法读取的页跳过，不改保护，不暂停/重试整次扫描。每个候选起点只归属于一个页/块，禁止跨不可读间隔拼接。页间取消检查保持及时。
3. 区域枚举保留现有地址空间边界，先核对 WOW64：仅接受到达相应 32/64 位地址空间顶部后的 ERROR_INVALID_PARAMETER 作为终止，不能把 64 位进程的中段错误当作 32 位正常结束。初始查询失败、其他错误或非法/不前进区域明确抛错。全部读取失败与无区域明确失败，不伪装“扫描成功、0 结果”；正常可读扫描没有匹配仍可返回 0。
4. 回归覆盖真实坏页、跨可读页/1 MiB 边界、对齐/不对齐、4/8 字节、多目标、无重复、取消、全部不可读、正常零匹配、枚举错误/终止/坏结构；保留原测试。诊断不打印内存地址。

三遍预检查：① 只修读边界，不改变游戏写入/候选存储/UI/API/兼容范围；② 快路径与失败路径有界，重叠失败不丢本页内部，不把坏页前后字节拼接，不伪造零结果；③ 先红后绿、真实 native 页变化加确定性故障注入，再做完整回归和产物门禁。历史失败没有直接现场证据这一限制必须保留。

## 实施后三遍检查

### 第一遍：确定性缺口与源码

真实自有 VirtualAlloc 区域在枚举后改一页为 NoAccess，标记位于另一仍可读页。旧算法在“标记直接读回有效、大块读取确已失败”前提下失败，修复后同一测试通过。默认入口保留 1 MiB 快路径，失败块有限按系统页读取；不解除保护、不写测试进程以外内存、不跨坏页拼接。诊断统计为 internal，SDK、公开 API/Schema 与游戏兼容名单不变。

### 第二遍：回归与安全

新增 65 项断言通过：native 页变化、4/8 字节、多目标、可读页/1 MiB 边界、绝对地址对齐、无重复、坏重叠保留本页内部、正常零结果、无区域/全读取失败、取消和临时存储释放、初始/中段查询错误、32/64 位终止与坏结构。使用每次不同标记的 12 次 GC 压力自扫描通过；保留原固定缓冲区和超过 250000 候选回归。完整 Release 构建 0 警告/0 错误，全部冒烟及现有三个模块九个页面通过；标准打包 10 项、离线包 80 项、版本保留 0–5 个模拟通过。原 0.4.9 两个 ZIP 与 SDK 合约散列不变。

### 第三遍：产物门禁

独立本地 review 包 `artifacts/local-review-b13e0f8f255d4f2dba288254527efd2f/GameValueEditor-local-review-v0.5.0-win-x64.zip` 的严格文件/版本检查、实际启动与更新器完整沙箱通过；再次独立启动验证通过。它包含未提交工作树、基线为 90d6b97，明确不是正式资产，SHA-256 `557D04A182C1C39AD6E6791AB33712546745B63988197269CD9FDAAFFDEA8FB9`。源码和新文件的空白/冲突检查通过。
