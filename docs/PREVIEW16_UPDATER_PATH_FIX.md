# v0.3.0-preview.16 更新目录规范化修正

## 问题

主程序使用 `AppContext.BaseDirectory` 启动独立更新器。该路径在 Windows 上已带有末尾目录分隔符；旧更新器无条件再追加一个分隔符，随后以字符串前缀判断更新文件是否仍位于应用目录内。结果是正常目标路径 `G:\Game\GameTools\CONTRIBUTING.md` 无法匹配错误构造的根路径 `G:\Game\GameTools\\`，安全检查把合法的根目录文件误报为越界路径并中止更新。

该故障不会覆盖用户数据或留下半更新程序。更新器在实际替换前完成路径检查，失败时清理事务目录、保留错误日志并继续使用旧版本。

## 修正

- 先将应用目录转换为绝对路径，仅在末尾没有目录分隔符时追加一次。
- 继续保留带目录边界的前缀检查，不能因为修复误报而放宽路径越界保护。
- 更新器沙箱测试显式传入带末尾分隔符的应用目录，模拟主程序实际使用的 `AppContext.BaseDirectory`。
- 沙箱仍验证临时文件占用后的重试、持续占用时的完整回滚，以及便携式 `data` 目录不被覆盖。

## 发布说明

preview.15 自带的旧更新器无法通过自动更新修复自身，受影响用户需要手动下载 preview.16 标准包，在程序完全退出后覆盖原安装目录。标准更新包不包含 `data`，现有游戏库和用户数据会保留。preview.16 起后续自动更新恢复正常。
